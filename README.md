# Хлоп — сайт студии бровей и ресниц

Статичный сайт без сборки: откройте `index.html` в браузере или загрузите папку на любой хостинг (GitHub Pages, Netlify, Vercel).

## Структура
```
index.html        разметка страницы
css/style.css     все стили, цвета в :root
js/data.js        прайс и услуги — цены меняются здесь
js/main.js        глаз, вкладки прайса, карточки, отзывы, анимации
js/booking.js     пошаговая запись: услуга → мастер → время → контакты
assets/           иллюстрации SVG и иконка сайта
```

## Что внутри
- Глаз в первом экране следит за курсором и моргает, вокруг вращается бейдж и разлетаются наклейки.
- Прайс по вкладкам, из любой строки можно перейти к записи с уже выбранной услугой.
- Карточки мастеров наклоняются в 3D, ленту отзывов можно тянуть мышью.
- Запись в 4 шага с маской телефона, проверкой полей и конфетти в конце.

Шрифты Unbounded и Manrope подключены с Google Fonts.
